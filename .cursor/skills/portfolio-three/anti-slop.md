# Anti-slop (WebGL)

`design-taste-frontend` bans landing-page tells. This
file bans **Three.js demo tells**. A recruiter has seen
all of these.

## Do not ship

- Default `BoxGeometry` / `TorusKnot` / `Icosahedron`
  spinning at origin
- `Text3D` / troika text of "Liam" or "HOLLOWAY"
- GLTF astronaut, skull, Japanese room, car, sword
- `OrbitControls` on the portfolio field (the page
  scrolls; the user is not in a sandbox)
- `Environment` HDR studio lighting on abstract points
- Unreal Bloom until the base field reads without it
- Mouse-following 3D cursor or custom GL cursor
- Per-section `<Canvas>` as a "cool embed"
- Particle explosion on every heading
- Shadertoy copy-paste with a different hex
- `drei` `<Stars />` as the whole scene
- Mixing this skill with Folio / product-ticket skills

## Do not load

- `design-taste-frontend` **instead of** this skill when
  the task is the field. Load it for type and layout,
  then come back here for GL.
- Extra animation libraries (`gsap`, `lenis`) to move
  meshes. Scroll progress is enough.

## Taste that fits this repo

Night ink, ice-blue telemetry, one teal spark. The
about orb is a **volume**, not a logo. Work's swirl can
stay 2D until the field grows a better cousin.

If a motif cannot be described as "abstract weather
over this section," delete it.

## Copy

User-facing strings still follow the site: no em dash
in DOM copy. Shader comments are not user-facing.
The canvas has no alt text (it is `aria-hidden`); do
not announce "3D background" in the skip link.
